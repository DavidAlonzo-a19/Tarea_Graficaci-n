Graficación por Computadora

Proyectos de Khan Academy llevados a HTML, CSS y JavaScript con p5.js

Bienvenido

Este sitio reúne los dibujos y animaciones que desarrollé en Khan Academy, adaptados ahora a código web estándar. Cada proyecto se dibuja sobre un elemento <canvas> usando la librería p5.js, y es interactivo: responde al mouse y a los clics.

Además, incluye dos apartados teóricos: uno sobre la etiqueta <canvas> y su contexto de renderizado 2D, y otro con los fundamentos de p5.js.
