El elemento <canvas>

Dibujo 2D en la web con el contexto de renderizado "2d"

¿Qué es <canvas>?

<canvas> es una etiqueta de HTML5 que crea una región rectangular en la página sobre la que se puede dibujar mediante JavaScript. Por sí sola no muestra nada: es solo un lienzo en blanco (un mapa de bits). Todo lo que aparece en él se dibuja con código. 

<canvas id="mi-lienzo" width="400" height="300">
  Tu navegador no soporta canvas.
</canvas>

Los atributos width y height definen el tamaño de la superficie de dibujo en píxeles (por defecto 300×150). El texto interior sirve de contenido alternativo para navegadores que no lo soportan o para lectores de pantalla.

Contextos de renderizado

Para dibujar hay que pedirle al canvas un contexto de renderizado con getContext(). El contexto es el objeto que contiene los métodos de dibujo. Los tipos disponibles son:

ContextoUso
"2d"Gráficos bidimensionales: formas, texto, imágenes y degradados.
"webgl" / "webgl2"Gráficos 3D acelerados por la GPU.
"bitmaprenderer"Mostrar de forma eficiente un ImageBitmap ya creado.

El contexto 2D

const canvas = document.getElementById("mi-lienzo");
const ctx = canvas.getContext("2d");

// Rectángulo relleno
ctx.fillStyle = "steelblue";
ctx.fillRect(20, 20, 150, 100);

// Círculo con contorno
ctx.beginPath();
ctx.arc(250, 70, 40, 0, Math.PI * 2);
ctx.strokeStyle = "crimson";
ctx.lineWidth = 4;
ctx.stroke();

Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. El eje X crece hacia la derecha y el eje Y crece hacia abajo.

Animación

Una animación se logra borrando el lienzo y redibujando en cada cuadro con requestAnimationFrame(): 

let x = 0;
function animar() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillRect(x, 50, 40, 40);
  x = (x + 2) % canvas.width;
  requestAnimationFrame(animar);
}
animar();

Relación con p5.js

p5.js crea un <canvas> con createCanvas() y usa internamente su contexto 2D, de modo que funciones como ellipse() o fill() son envoltorios más cómodos de métodos como arc() y fillStyle. Esa es la razón por la que los dibujos de este sitio se ven en un canvas estándar.
