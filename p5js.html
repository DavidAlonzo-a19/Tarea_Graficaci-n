Fundamentos de p5.js

La librería usada para crear los dibujos y animaciones interactivos

¿Qué es p5.js?

p5.js es una librería de JavaScript para programación creativa, basada en la filosofía de Processing. Facilita dibujar, animar e interactuar en el navegador sin escribir el código repetitivo de la API de canvas. Es la evolución natural de lo que en Khan Academy se hacía con ProcessingJS.

Se incluye en la página con una etiqueta <script>:

<script src="https://cdn.jsdelivr.net/npm/p5@1.9.4/lib/p5.min.js"></script>
<script src="js/mi-dibujo.js"></script>

Estructura básica: setup() y draw()

function setup() {
  createCanvas(400, 400);   // se ejecuta una sola vez
}

function draw() {
  background(220);          // se ejecuta ~60 veces por segundo
  ellipse(mouseX, mouseY, 50, 50);
}
  • setup(): configuración inicial; aquí se crea el canvas.
  • draw(): se repite continuamente; cada ejecución es un cuadro de la animación.
  • preload(): opcional, carga imágenes o fuentes antes de iniciar.

Formas, color y estilo

FunciónDescripción
background(r, g, b)Pinta todo el fondo.
fill() / noFill()Color de relleno de las formas siguientes.
stroke() / noStroke()Color del contorno.
strokeWeight(n)Grosor del contorno.
rect(), ellipse(), triangle(), line(), arc()Formas primitivas.
text(), textSize()Texto en el lienzo.

El color se puede dar como escala de grises fill(128), RGB fill(255, 0, 0), con transparencia fill(255, 0, 0, 100) o como cadena fill("#ff0000").

Variables del sistema y animación

p5.js ofrece variables que se actualizan solas:

  • width y height: tamaño del canvas.
  • mouseX, mouseY, mouseIsPressed: estado del mouse.
  • frameCount: número de cuadros dibujados (útil para animar con sin()).

La animación se logra cambiando una variable en cada ejecución de draw() y dibujando con su nuevo valor. Por ejemplo, los copos de nieve de Día nevado soleado guardan su posición en un arreglo y suman a y en cada cuadro.

Interactividad: eventos

function mousePressed() {   // se llama al hacer clic
  sombrero = !sombrero;
}
function keyPressed() {     // se llama al presionar una tecla
  if (key === " ") reiniciar();
}

Otros eventos útiles: mouseReleased(), mouseMoved(), keyReleased().

Transformaciones

translate(), rotate() y scale() modifican el sistema de coordenadas. Se combinan con push() y pop(), que guardan y restauran el estado de dibujo, para afectar solo a un grupo de formas (como los rayos giratorios del sol).

Funciones matemáticas útiles

random(), map(), lerp(), dist(), sin(), cos(), atan2(), constrain().

Modo global e integración con la página

Los ejemplos de este sitio usan el modo global: setup y draw se declaran como funciones globales y p5.js las detecta solas. Con createCanvas(400, 400).parent("lienzo") el canvas se coloca dentro del <div id="lienzo"> de la página, y p5.js genera el elemento <canvas> con su contexto 2D.
