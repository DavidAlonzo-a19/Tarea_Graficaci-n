# Graficación: dibujos con canvas y p5.js

Sitio web con los proyectos de Khan Academy adaptados a HTML, CSS y JavaScript (p5.js).

## Contenido (todos los archivos están en la raíz)
- `index.html`: página principal con el menú
- `canvas.html`: teoría del elemento `<canvas>` y su contexto 2D
- `p5js.html`: fundamentos de p5.js
- `rana.html`, `conejo.html`, `cena.html`, `nevado.html`, `muneco.html`: los cinco dibujos
- `dom-inspector.html`: árbol visual del DOM de cada página del sitio (usa `dom-inspector.js` y `dom-data.js`)
- `style.css`: estilos del sitio
- `nav.js`: menú de navegación; `dom-inspector.js`, `dom-data.js`, `rana.js`, `conejo.js`, `cena.js`, `nevado.js`, `muneco.js`: código de cada dibujo

## Ver el sitio
Abre `index.html` en el navegador (requiere internet para cargar p5.js desde el CDN).
